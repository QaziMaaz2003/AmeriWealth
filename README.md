# AmeriWealth Financial

Marketing website for AmeriWealth Financial — Craig Anger, Retirement Specialist and Certified Financial Fiduciary.

Built with Next.js (App Router), TypeScript, and Tailwind CSS v4.

## Pages

- `/` — Home
- `/about` — About Craig Anger
- `/services` — Retirement planning, life insurance, investments, and financial consulting
- `/contact` — Contact form (submits via [FormSubmit](https://formsubmit.co) to `ameriwealth07@gmail.com`)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Contact form

The contact form posts to FormSubmit without a backend. **The first real submission after deploying will trigger a one-time activation email to `ameriwealth07@gmail.com`** — click the confirmation link in that email to start receiving form submissions.

## Build

```bash
npm run build
npm start
```
